## 🚀 Projects

### 📟 1. Automatic Traffic Clearance System for Ambulance
* **Hardware & Tech Stack:** ESP32, Wi-Fi/BLE, RF modules, IR/Ultrasonic Sensors, Embedded C.
* **Description:** Designed an intelligent traffic management system that preemptively alters traffic light sequences upon detecting an approaching emergency vehicle. Used ESP32 modules to broadcast signal overrides, minimizing delay times for emergency responders.

### 📍 2. Smart GPS Geofencing System
* **Hardware & Tech Stack:** Arduino UNO, NEO-6M GPS Module, SIM900A GSM Module, Embedded C.
* **Description:** Developed a localized asset tracking and security mechanism. The system continuously polls GPS coordinates and matches them against user-defined polygon boundaries. Triggering a geofence breach instantly dispatches an SMS alert with real-time Google Maps coordinates via the GSM network.

### 🌐 3. IoT-Based Real-Time Monitoring Environments
* **Hardware & Tech Stack:** ESP32/ESP8266, MQTT Protocol, ThingSpeak, Low-power Sensors.
* **Description:** Built telemetry platforms targeted at environmental and industrial parameter monitoring. Focused on writing robust data parsing algorithms, ensuring continuous connection upkeep, handling network disconnections gracefully, and pushing clean sensor arrays to analytical dashboards via MQTT.
